# Checklist de Fidelidade

## Experiência central

- [x] A câmera permanece fixa atrás do carro.
- [x] O objetivo continua sendo ultrapassar veículos.
- [x] O primeiro dia autêntico exige 200 ultrapassagens.
- [x] Os dias autênticos seguintes exigem 300 ultrapassagens.
- [x] O jogo avança por dias, sem linha de chegada definitiva.
- [x] A falha ocorre quando a meta não é cumprida antes do amanhecer.
- [x] Uma meta concluída permite dirigir até o novo amanhecer.
- [x] O contador principal diminui uma vez por veículo ultrapassado.
- [x] Não existem voltas, posição de corrida ou adversários nomeados.

## Assinaturas ambientais

- [x] A noite enfatiza lanternas traseiras e preserva silhuetas.
- [x] A neblina reduz progressivamente visibilidade e contraste distante.
- [x] O gelo reduz a resposta da direção e aumenta a inércia lateral.
- [x] Colisões reduzem imediatamente a velocidade.
- [x] A dificuldade aumenta a cada dia por velocidade e formação do tráfego.

## Restrições

- [x] Não existe minimapa.
- [x] Não existe nitro.
- [x] Não existem checkpoints modernos.
- [x] Não existem elementos de simulador mecânico complexo.
- [x] Não existem moedas, compras, garagem ou recompensas diárias.
- [x] Nenhum asset protegido ou marca de fabricante é usado.

## Passe visual (Marco 4)

- [x] Carro do jogador original em três poses traseiras coerentes.
- [x] Sedã e caminhão de tráfego originais, sem marcas ou fabricantes reais.
- [x] Panorama montanhoso sem emendas visíveis.
- [x] Microtextura de asfalto preserva linhas, acostamentos e leitura de profundidade.
- [x] Noite preserva silhuetas, lanternas e faróis com os novos assets.
- [x] Colisão apresenta reação visual e faíscas sem bloquear rotas de fuga.
- [x] Menu, HUD e diagnósticos permanecem legíveis em desktop e celular horizontal.

## Áudio e acabamento (Marco 5)

- [x] Motor, vento e pneus respondem à velocidade sem usar áudio protegido.
- [x] O gelo altera o som dos pneus e colisões continuam tendo resposta imediata.
- [x] Sinais de ultrapassagem, período, meta, novo dia e fim de jogo não alteram regras.
- [x] Gamepad oferece a mesma aceleração, frenagem, direção, pausa e confirmação dos outros controles.
- [x] Legacy e Hyper mantêm exatamente câmera, objetivo, contador e simulação.
- [x] A transição Legacy → Hyper não contém sprites, fontes ou imagens do jogo original.
- [x] Tela cheia é opcional e possui fallback jogável.
- [x] A PWA mantém os dois modos de identidade e funcionamento offline após o primeiro carregamento.

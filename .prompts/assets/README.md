# Prompts de assets

Prompts finais usados no Marco 4. Cada arquivo registra enquadramento, iluminação, escala, restrições de marca, chroma key e critérios de aprovação. As imagens são originais, produzidas pelo ImageGen e pós-processadas localmente; nenhum recurso protegido foi usado.

- `player-car-center.md`, `player-car-left.md`, `player-car-right.md`: três poses coerentes do carro do jogador.
- `traffic-sedan.md`, `traffic-truck.md`: famílias base do tráfego, colorizadas e escaladas pelo Canvas.
- `mountain-panorama.md`: silhueta atmosférica para a paisagem em camadas.
- `asphalt-texture.md`: microtextura sem emendas aplicada à pista pseudo-3D.
